# 완료 전 검증

## 절차

1. 이번에 바꾼 요구사항 번호를 PLAN.md에서 찾는다
2. 요구사항마다 확인 수단을 하나 이상 실행한다
   - 테스트가 있으면 해당 테스트를 돌린다
   - 없으면 가장 작은 테스트를 추가하거나, 재현 명령(curl, 스크립트 실행)을 만든다
   - 정상 입력 하나, 경계 입력 하나, 잘못된 입력 하나를 확인한다
3. 서버가 있는 과제
   - 서버가 `0.0.0.0`에 바인딩되어 있는지 확인한다
   - 실제 포트와 경로를 사용자에게 알려 Browser 미리보기에서 눌러 볼 항목을 목록으로 준다
4. 전체 테스트를 다시 돌려 이전 기능이 깨지지 않았는지 본다
5. 통과하면 commit한다

## 보고 형식

```
확인한 것: (명령) → (결과 요약)
확인하지 못한 것: (항목과 이유)
남은 위험: (있으면)
```

실행하지 않은 확인을 "통과"라고 쓰지 않는다. 출력이 길면 핵심 줄만 인용한다.
